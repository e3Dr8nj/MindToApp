➕ Добавить модуль

Вставьте прямую ссылку на файл с HTML-кодом или на папку.
Поддерживаются любые форматы: .html, .txt, GitHub Gist (Raw), GitHub Pages и другие хостинги.

Примеры:
• https://username.github.io/my-app/
• https://gist.githubusercontent.com/.../raw/file.html
• https://gist.githubusercontent.com/.../raw/file.txt

Выберите один файл .html с вашего компьютера.

Выберите папку с модулем (должен быть index.html).

⚠️ Работает в Chrome, Edge, Firefox. Не работает в Safari.

Вставьте полный HTML-код приложения. Код должен содержать <script id="manifest"> в <head>.
