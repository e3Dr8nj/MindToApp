🤖 Промпт для AI

Скопируйте текст ниже и добавьте его в начало вашего промпта при разработке приложения через ChatGPT, Claude или другую AI-модель. После промпта опишите, какое приложение вы хотите создать.

Как использовать:

  1. Нажмите кнопку «Копировать»
  2. Вставьте в чат с AI-моделью
  3. Вместо [опиши здесь...] напишите свою идею
  4. Сохраните полученный код как файл .html
  5. Добавьте файл в платформу через кнопку «➕ Добавить»

➕ Добавить модуль

Вставьте ссылку на HTML-файл или папку с модулем.
Пример: https://username.github.io/my-module/

Выберите один файл .html с вашего компьютера.
(Модуль должен быть одним файлом со встроенными стилями и скриптами)

Выберите папку с модулем на вашем компьютере.
В папке должен быть файл index.html и любые сопутствующие файлы

⚠️ Работает в Chrome, Edge, Firefox. Не работает в Safari.
